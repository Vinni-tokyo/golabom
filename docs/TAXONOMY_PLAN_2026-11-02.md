# 골라보셈 명품관 분류 체계 기획안

- 작성: 2026-11-02
- 대상: 명품관 75관(약 60분씩)과 그 안의 영상 약 700편
- 상태: **제안**입니다. 결정 전에는 사이트를 바꾸지 않습니다.

---

## 0. 쉽게 읽는 요약

**예시.** 성경관을 찾으려는 사람이 「무엇을」 문을 엽니다. 그런데 성경관은 「생각과 말」 칸에서 철학관과 의심관 사이에 있습니다. 「믿음」 관은 엉뚱하게 「늙음과 죽음」 칸에 있습니다. 어학관 세 개는 열네 칸 가운데 맨 끝에 있습니다. 「언제」 문을 열면 「잠들기 전」이 나오고, 「몇 년대」 문을 열면 「1990년대」가 나옵니다. 둘 다 시간인데 하나는 관을 보여 주고 다른 하나는 영상을 보여 줍니다.

**원인.** 성격이 다른 세 가지를 한 줄에 세워 두었습니다.

- 관이 **무엇에 관한 것인가**: 주제
- 관을 **언제 보면 좋은가**: 상황
- 영상이 **어디서·어떤 꼴로·언제 만들어졌나**: 작품 속성

육하원칙은 사건 하나를 설명하는 틀입니다. 서가를 나누는 틀로는 맞지 않습니다.

**바꿀 것.** 도서관(KDC)과 서점, 스포티파이가 공통으로 쓰는 방식을 따릅니다.

1. **주제 서가 9칸.** 관마다 꽂히는 자리는 딱 하나입니다(도서관의 주류).
2. **이럴 때.** 상황별로 관을 모아 둔 서가입니다. 한 관이 여러 곳에 있어도 됩니다(스포티파이의 「잠들기 전」).
3. **사람과 시대.** 한 사람, 한 시대를 깊이 보는 관들입니다(박물관의 인물전).
4. **영상으로 찾기.** 나라·형식·연대는 문이 아니라 **필터**로 바꿉니다(도서관의 보조표).

문이 8개에서 3개와 필터 하나로 줄고, 75관 모두 주제 서가에 한 자리씩 들어갑니다(§5 배치표).

**결정할 것.** 4가지입니다(§10).

## 1. 지금 무엇이 문제인가

| 문 | 보여 주는 것 | 문제 |
|---|---|---|
| 누가 | 관 8개(한 사람·한 시대) | 이름만 보고는 「사람이 나오는 관」인지 「만든 사람」인지 모릅니다 |
| 언제 | 관(잠들기 전·가는 길에 등 5칸) | 「몇 년대」와 같은 시간 축으로 읽힙니다 |
| 어디서 | **영상**(나라 13곳) | 문을 열면 관이 아니라 영상이 나와 앞의 두 문과 결이 다릅니다 |
| 무엇을 | 관(장르 14칸) | 주제(스포츠·기술)와 삶의 테마(가족·용기·죽음)가 섞여 있습니다. 「손과 기술」과 「기술」은 이름이 겹치고, 「이럴 때」·「19」 같은 남은 칸도 있습니다 |
| 어떻게 | **영상**(형식 9가지) | 「무대·다큐·강연」은 쓸모 있지만 문 이름이 무엇을 거르는지 말해 주지 않습니다 |
| 왜 | 관(위로가 필요할 때 등 7칸) | 「언제」와 성격이 같아 둘을 나눌 이유가 없습니다 |
| 무엇으로 | **영상**(재료 13가지) | 「쇠와 기계」·「글과 말」로 영상을 고르는 사람은 드뭅니다. 랑가나탄 이론에는 맞지만 쓰는 사람의 말이 아닙니다 |
| 몇 년대 | **영상**(연대 8칸) | 쓸모는 있지만 「언제」와 부딪힙니다 |

그 결과 이런 일이 생깁니다.

- 「생각과 말」에는 철학·글쓰기·언어학·아동 발달·감정·성경이 함께 들어 있습니다.
- 「믿음」(belief)은 「늙음과 죽음」에 있습니다.
- 「언어가 생각을 바꾼다」(language)는 「어학」이 아니라 「생각과 말」에 있습니다.
- 새 관을 만들 때마다 어느 칸에 넣을지 기준이 없어, 그때그때 정하게 됩니다.

## 2. 기존 분류 체계 살펴보기

| 체계 | 큰 줄기(한 가지 기준) | 다른 기준은 어떻게 다루나 | 우리가 배울 점 |
|---|---|---|---|
| **도서관 KDC** | 주류 10개: 총류·철학·종교·사회과학·자연과학·기술과학·예술·언어·문학·역사 | 형식·지역·시대·언어는 **보조표**로 번호 뒤에 붙입니다. 주류와 같은 높이에 두지 않습니다 | 주제는 하나로 정하고, 나머지는 덧붙이는 속성으로 다룹니다 |
| **듀이 십진분류(DDC)** | KDC와 같은 구조의 10개 주류 | 표준세구분(형식)·지역·시대 보조표 | KDC와 같습니다 |
| **랑가나탄 콜론분류(PMEST)** | 성격·재료·활동·공간·시간 다섯 면을 조합 | 모든 면이 같은 높이 | 이론으로는 완전하지만 **이용자용 서가로는 쓰지 않습니다.** 사서가 번호를 매길 때 쓰는 도구입니다. 지금 우리의 「무엇으로」·「몇 년대」가 여기서 왔습니다 |
| **서점(교보문고 등)** | KDC를 쉬운 말로: 인문·과학·예술·외국어·종교·건강·스포츠·컴퓨터/IT·역사… | 「테마 기획전」·「베스트」는 따로 둡니다 | 주제 이름은 **이용자가 쓰는 말**로 짓습니다 |
| **포털 지식백과·위키백과 대문** | 문화·예술, 지리, 건강, 역사, 자연, 철학, 종교, 사회, 기술 | 인물·시대는 별도 포털 | 인물과 시대는 주제와 따로 둡니다 |
| **YouTube 범주** | 음악·스포츠·교육·과학기술·영화·뉴스·여행… | 형식(쇼츠·라이브)은 필터 | 주제와 형식을 섞으면 이상해집니다(「교육」과 「과학기술」이 겹침) |
| **넷플릭스** | 장르 줄 | 「기분이 좋아지는」 같은 **기분 줄**은 장르와 따로 | 상황·기분은 주제와 다른 층에 둡니다 |
| **스포티파이** | 장르 | 「잠들기 전」·「집중」 같은 **상황 서가**는 따로 | 우리의 「언제」와 「왜」를 한 층으로 합칠 근거입니다 |
| **박물관** | 상설관은 주제나 시대별 | 기획전과 인물전은 따로 | 「한 사람」·「한 시대」 관은 따로 모읍니다 |

**공통된 결론.**

1. 이용자가 처음 고르는 기준은 **주제 하나**이고, 한 대상은 한 자리에 꽂힙니다.
2. **상황·기분**은 주제와 다른 층으로, 한 대상이 여러 곳에 들어가도 됩니다.
3. **형식·지역·시대**는 문이 아니라 **거르는 조건**입니다.
4. 이름은 **분류 이론의 말이 아니라 이용자의 말**로 짓습니다.

## 3. 설계 원칙

1. **한 관은 주제 서가 하나에만 꽂힌다.** 새 관을 만들 때 서가를 반드시 하나 정합니다. 린트가 확인합니다.
2. **서가는 9칸, 한 칸은 4~12관.** 너무 작으면 합치고, 너무 크면 서가 안에 「작은 칸」을 둡니다.
3. **상황과 사람은 겹쳐도 된다.** 「이럴 때」와 「사람과 시대」에는 한 관이 여러 번 나와도 됩니다.
4. **영상의 속성은 필터다.** 나라·형식·연대는 영상 단위로 거르는 조건입니다.
5. **이름은 서점 말로.** 「무엇으로」 같은 이론 용어는 쓰지 않습니다.

## 4. 새 구조

```
명품관
├─ [주제]          ← 기본으로 열리는 문 · 관마다 한 자리
│   스포츠 · 음악 · 예술과 만들기 · 과학과 자연 · 기술
│   역사와 사회 · 철학과 종교 · 언어 · 삶과 사람
├─ [이럴 때]       ← 「언제」+「왜」를 합친 상황 서가 · 겹쳐도 됨
│   쉬고 싶을 때 / 마음이 필요할 때 / 함께 볼 때 / 궁금할 때
├─ [사람과 시대]   ← 지금의 「누가」
│   한 사람 / 한 시대
└─ 🔎 영상으로 찾기 ← 문이 아니라 필터 화면
    나라 13곳 × 형식 9가지 × 연대 8칸 (겹쳐 고르기)
```

**지금의 8문과 대응.**

| 지금 | 새 자리 |
|---|---|
| 무엇을 | **주제** (14칸 → 9칸으로 다시 짬) |
| 언제 + 왜 | **이럴 때** (한 층으로 합침) |
| 누가 | **사람과 시대** |
| 어디서 · 어떻게 · 몇 년대 | **영상으로 찾기** 필터 (나라 · 형식 · 연대) |
| 무엇으로 | **뺌** (영상 데이터의 태그는 남겨 둡니다. 「여기서 더 파기」 같은 곳에서 쓸 수 있습니다) |

## 8. 「🔎 영상으로 찾기」 필터

- 한 화면에서 **나라 · 형식 · 연대**를 겹쳐 고릅니다. 예: 「일본 × 무대 × 1990년대」.
- 결과는 지금처럼 영상 띠로 보이고, 「▶ 이어 보기」로 연달아 봅니다.
- 데이터는 이미 있습니다(`app/data/facets.json`). 화면만 문 네 개에서 필터 한 장으로 바꿉니다.

## 9. 지난번 3문과 무엇이 다른가

## 10. 결정할 것

1. **구조**: 3문 + 영상 필터(이 안)로 갈까요, 8문을 두고 이름만 정리할까요?
2. **「무엇으로」(재료)**: 화면에서 빼도 될까요? 태그 데이터는 남깁니다.
3. **서가 이름**: 「예술과 만들기」, 「삶과 사람」, 「철학과 종교」로 괜찮을까요?

   - 「탐험가들」 → 역사와 사회
   - 「글쓰기의 비밀」 → 예술과 만들기
