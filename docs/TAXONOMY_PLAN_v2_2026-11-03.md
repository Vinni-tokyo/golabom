# 골라보셈 명품관 분류 체계 v2 — 도서관식 대주제·소주제

- 작성: 2026-11-03 · v1(11-02)의 「주제 9칸 + 작은 칸」을 도서관 서가처럼 **대주제 → 소주제** 두 층으로 다시 짰습니다.
- 상태: **제안**입니다. 결정 전에는 사이트를 바꾸지 않습니다.

## 0. 쉽게 읽는 요약

도서관에 들어가면 먼저 「예술」·「과학」·「역사」 같은 큰 팻말이 보이고, 그 서가 앞에 서면 「음악」·「미술」 같은 작은 팻말이 보입니다. 두 번만 고르면 책에 닿습니다. 명품관도 그렇게 바꿉니다.

- **대주제 8칸**: 예술 · 스포츠 · 과학과 자연 · 기술 · 생각과 믿음 · 역사와 사회 · 사람과 삶 · 외국어
- **소주제 23칸**: 대주제마다 2~4칸. 한 칸에 2~6관.
- **관 75개는 모두 자리가 하나씩**입니다. 상황관 4개만 「이럴 때」 서가에 둡니다.
- 「이럴 때」(상황)와 「사람과 시대」(인물·시대)는 지금처럼 따로 두고, 나라·형식·연대는 「영상으로 찾기」 필터로 뺍니다(v1과 같음).

**결정할 것**: 대주제 이름 2개(「생각과 믿음」·「사람과 삶」), 경계에 있는 관 5개의 자리(§3), 19관 처리(§4), 모아 보기 첫 묶음(§7).

---

## 1. 왜 다시 짰나

v1의 「주제 9칸 + 작은 칸」은 칸 이름이 설명문에 가까웠고(「예술과 만들기」·「삶과 사람」), 작은 칸이 화면에서 어떻게 보이는지 정하지 않았습니다. 도서관 분류의 힘은 **두 층이 늘 같은 모양**이라는 데 있습니다. 어느 서가에 가도 「큰 팻말 → 작은 팻말 → 책」입니다.

## 5. 화면

```
명품관
├─ [주제]   대주제 8칸이 가로 탭 → 아래에 소주제 팻말 → 관 카드   ← 기본 문
├─ [이럴 때]   상황 서가 12칸(4묶음) · 상황관 4 + 겹치는 관
├─ [사람과 시대]   한 사람 / 한 시대
└─ 🔎 영상으로 찾기   나라 × 형식 × 연대 필터
```

- 대주제 탭은 한 줄(8칸). 폰에서는 두 줄로 접힙니다.
- 소주제 팻말은 관이 2개뿐이어도 둡니다. 팻말이 「무엇이 있는 서가인지」를 말해 주기 때문입니다.
- 「물어보기」 큐레이터는 이 두 층을 그대로 지식으로 씁니다(「되묻는 이」는 다른 대주제에서 고릅니다).

## 7. 모아 보기 — 서가를 가로지르는 특집 몇 개 (11-03 추가)

도서관의 「이달의 특집」 매대처럼, **대주제·소주제와 상관없이** 키워드 하나로 영상을 모읍니다. 관(한 시간 묶음)이 아니라 **영상 단위**입니다. 여러 관에 흩어진 작품이 한 줄로 모입니다.

| 모음 | 모으는 기준 | 지금 데이터로 몇 편 |
|---|---|---|
| **AI** | 기술 › 인공지능 5관 전체 + 다른 관의 AI·인공지능·알고리즘 작품(예: 사피엔스의 알고리즘 장) | 약 50편 |
| **스포츠** | 스포츠 7관 전체 + 다른 관의 경기 형식(「어떻게 › 경기」) 작품 | 약 70편 |
| **라이브 무대** | 형식이 「무대」인 작품 전부(음악 10관 + 춤·한국의 소리) | 약 160편 |
| **우주** | 우주 2관 + 「하늘과 별」 재료 작품 | 약 40편 |
| **부모** | 아버지·어머니·부모·할머니가 제목이나 명판에 든 작품 | 약 20편 |
| **오늘 뜨는 것** | 트렌드 화면의 인기 급상승·구글 검색어 영상(매시 갱신) | 매일 다름 |

- 개수는 **4~6개**로 유지합니다. 많아지면 다시 분류가 됩니다.
- 기준은 `tools/gallery_catalog.json`의 `features`(관 목록 + 형식 + 재료 + 제목 낱말)로 적고, 빌드가 `app/data/features.json`에 영상 목록을 만듭니다. 손으로 고른 작품은 `pins`로 앞에 둡니다.
- 화면: 명품관 첫 화면 맨 위, 대주제 탭 **위에** 가로 띠 「모아 보기」. 누르면 영상 격자 + 「▶ 이어 보기」. 「영상으로 찾기」 필터와 같은 화면 틀을 씁니다.
- 「물어보기」의 길잡이도 목표가 모음 이름과 맞으면(「AI」·「축구」) 관보다 먼저 그 모음을 권합니다.
- 바꾸는 순서 2번(빌드)과 3번(화면)에 같이 넣습니다.

## 6. 바꾸는 순서 (결정 후)

1. `tools/gallery_catalog.json`에 `subjects: [{id, name, groups: [{name, halls}]}]`를 두고(SSOT), `gallery_themes.json`의 `_genre`는 여기서 만들어 쓰거나 없앱니다.
2. `build_gallery.py`가 index.json의 doors에 subjects를 싣고, lint가 「자리 없는 관」·「두 자리인 관」을 잡습니다.
3. `gallery.js`: DOORS 3개 + 필터 화면, 주제 문은 「대주제 탭 → 소주제 팻말」.
4. `ask.js`: 장르 대신 대주제·소주제로 「다른 시각」을 고릅니다.

되돌리기는 커밋 하나로 됩니다. 데이터는 지우지 않습니다.
