## 0. 쉽게 읽는 요약

**예시.** ABC마트에 가면 나이키 매장, 아디다스 매장을 따로 돌지 않아도 여러 브랜드의 괜찮은 신발을 한곳에서 고릅니다. 영상은 그렇지 않습니다. YouTube · Vimeo · TikTok · TED 를 따로 돌아야 하고, 각 플랫폼은 자기 영상만 보여 줍니다.

**원인.** 영상을 **플랫폼을 가리지 않고 골라 모아 주는 곳**이 없습니다. 여러 플랫폼을 한 번에 찾는 검색은 예전부터 있었지만 원본 사이트로 보내기만 했고, 상당수는 문을 닫았습니다.

**바꾼 것.**

- 골라봄을 **「영상의 ABC마트」**로 정의합니다. 여러 플랫폼의 좋은 영상을 한곳에서 고르고, 그 자리에서 봅니다.
- 첫 상품은 **명작 갤러리**입니다. 세상의 수많은 영상 가운데 정말 가치 있는 것만 골라 **테마별 전시관**으로 만들고, 둘러보는 즐거움을 줍니다.
- 여러 플랫폼을 「검색」하는 것은 지금 거의 막혀 있습니다(YouTube · Dailymotion · 니코니코만 가능). 대신 **사람이 골라 「진열」하는 것은 퍼가기만 있으면 되므로 지금 바로 됩니다.** 그래서 갤러리부터 시작합니다.

**결과(판정 기준).** Step 0 의 통과 기준(5명 중 3명이 주 2회 이상 재방문)은 그대로입니다. 갤러리 1호에 대해서는 **다시 열었는가 · 3편 이상 봤는가 · 남에게 전했는가** 세 가지를 따로 셉니다.

**결정할 것.** 3가지입니다(§7). 갤러리 1호 테마, 섞을 플랫폼, 「추천 신청」을 여는 시점입니다.

## 1. 한 줄 정의

> **골라봄은 영상의 ABC마트입니다.** 여러 플랫폼에서 정말 볼 만한 영상만 골라, 한곳에서 둘러보고 바로 봅니다.

**같은 날 더한 위치 (사용자):** 기존 영상 플랫폼은 무엇이든 쌓이는 **돗대기 시장**입니다. 골라봄은 다릅니다. **영상의 백화점, 그것도 명품관**입니다. 쓰레기 영상은 처음부터 들이지 않습니다.

| ABC마트 | 골라봄 |
|---|---|
| 여러 브랜드의 신발 | 여러 플랫폼의 영상(YouTube · Vimeo · TED · TikTok …) |
| 바이어가 고른 진열 | **명작 갤러리**(테마 전시관) · RESERVE(개인 추천) |
| 매장에서 신어 보기 | 골라봄 화면 안에서 바로 재생(공식 퍼가기) |
| 진열대 찾아가기 | 버튼으로 만드는 정밀 검색 · 지금 뜨는 키워드 |
| 정품만 판다 | **영상을 내려받거나 다시 올리지 않는다.** 공식 퍼가기만 쓴다 |

## 2. 명작 갤러리

### 2.1 무엇인가

- **테마 하나에 12~20편**을 모은 전시관입니다. 예: 「장인의 손」, 「처음 보는 지구」, 「10분 안에 세계관이 바뀌는 강연」.
- **편마다 한 줄 해설**이 붙습니다. 왜 이 영상이 명작인지, 어디를 봐야 하는지 씁니다. 이것이 골라봄이 파는 가치입니다.
- **플랫폼을 섞습니다.** 같은 테마 안에 YouTube · Vimeo · TED 영상이 나란히 놓입니다. 카드마다 출처 플랫폼을 따로 표시합니다(YouTube 규정 III.F.2).

### 2.2 왜 사람들이 들어오고 싶어 할까 (브랜드 선순환)

1. **보는 사람:** 아무 영상이나 넘기는 피로 대신, 믿을 수 있는 전시를 둘러보는 즐거움을 얻습니다.
2. **골라봄 브랜드:** "골라봄 갤러리에 들어간 영상 = 볼 만한 영상"이라는 신뢰가 쌓입니다.
3. **크리에이터:** 갤러리에 오르면 「골라봄 선정」이라는 훈장과 노출이 생깁니다. 그래서 들어오고 싶어집니다.
4. **플랫폼:** 처음에는 연결을 경계할 수 있습니다. 하지만 골라봄이 좋은 시청자를 보내 주는 곳이 되면, 노출을 위해 먼저 손을 내밀 수 있습니다.

### 2.3 단계

| 단계 | 내용 | 시점 |
|---|---|---|
| ① 첫 전시 | **처음부터 12관**으로 연다(사용자 결정). 1호 「장인의 손」 · 테스터 5명에게 보여 주고 잰다 | **Step 0 2주차(리저브 Vol.2 자리)** |
| ② 갤러리 여러 개 | 테마를 늘리고, 홈에 「명작 갤러리」 칸을 둔다 | Step 0 통과 뒤 |
| ③ 추천 신청 | 크리에이터가 **이미 다른 플랫폼에 올린 영상 링크**를 제출하고, 운영자가 심사한다 | 모르는 사람의 재방문이 꾸준히 생긴 뒤 |
| ④ 직접 업로드 | 골라봄에 영상을 직접 올리게 한다 | **지금은 하지 않음.** 호스팅 비용·저작권·신고 대응·법적 책임이 개인 프로젝트에 무겁다. ③ 의 반응을 보고 다시 판단한다 |

### 2.4 명품 입점 기준

갤러리에 걸리려면 **모두** 통과해야 합니다.

1. **원작자나 공식 배급처의 영상**입니다. 다시 올린 영상은 받지 않습니다.
2. **만듦새가 좋습니다.** 촬영, 소리, 호흡, 글이 모두 정성스럽습니다.
3. **오래갑니다.** 5년 뒤에 봐도 볼 가치가 있습니다.
4. **낚시 제목·썸네일, 리액션, 짜깁기, 「TOP 10」, 광고성 영상, AI 로 대량 생산한 영상이 아닙니다.**
5. **3~30분을 기본으로 합니다.** 1분 안팎의 짧은 영상은 정말 뛰어날 때만 받습니다.
6. **한 전시관 안에서 나라와 만든 사람이 고루 섞입니다.** 한 채널은 2편까지입니다.
7. **우리 화면에서 실제로 재생됩니다.** 존재와 퍼가기를 확인하지 못한 영상은 걸지 않습니다.

| No. | 전시관 | 한 줄 |
|---|---|---|

### 2.6 디자인: 밤의 미술관 (사용자 결정)

- 어두운 벽, 작품(영상)에만 조명이 비치는 느낌입니다. 제목은 세리프, 금빛은 아주 조금만 씁니다.
- 영상은 **액자에 걸린 작품**, 큐레이터 해설은 **작품 옆 명판**처럼 보이게 합니다.
- 작품을 누르면 **관람실**(화면 가득 어두운 배경)에서 재생하고, 이전·다음 작품으로 이어 봅니다.
- 홈에는 검색창 바로 아래에 **「명작 갤러리」 입구 띠**를 둡니다.

### 2.7 옴니버스 — 이어 보는 이야기 (시범 · 사용자 요청 2026-10-30)

한 테마의 작품들에서 장면을 조금씩 골라, 이야기 카드와 함께 이어 틀어 **한 편의 이야기**로 보게 합니다. 시범은 「장인의 손」의 **『손이 기억하는 것』**(6장면 · 약 8분)입니다.

**지키는 선.** 영상을 내려받거나 자르거나 합치지 않습니다. 그렇게 만든 파일은 남의 작품으로 만든 새 작품이라 저작권 침해이고, YouTube 규정(III.E.1.a 내려받기 금지 · III.I.7 영상·소리 분리·변경 금지)에도 어긋납니다. 대신 **각 플랫폼의 공식 플레이어로 「그 구간만」 차례로 틉니다.** 카드는 플레이어 위에 덮지 않고 플레이어 사이에만 둡니다(III.I.6). 장면마다 원작·만든 사람·「전편 보기」를 붙입니다. 「구간만 이어 틀기」를 직접 다룬 조항은 없어서(원문 확인) 금지는 아니지만 회색 지대입니다. 그래서 시범으로 작게 합니다.

**구간을 자동으로 정하는 법 (`tools/omnibus_scout.py`).** 사람이 영상을 보지 않아도 되도록, 규정 안의 공개 정보만 씁니다.

1. **설명란 챕터**: 「5:48 손잡이와 주둥이」 같은 시간표(공식 API · 1단위)
2. **25% · 50% · 75% 지점의 공개 장면**: YouTube 가 공개하는 `1.jpg` `2.jpg` `3.jpg`. 모델이 이 장면을 보고 「손이 나오는 지점」을 고릅니다
3. **설명란 글**: 「앞부분은 수공, 뒷부분은 기계」 같은 단서

자막은 쓰지 않습니다. 공식 API 로는 영상 주인만 받을 수 있고, 시범 9편 중 자막이 있는 것도 3편뿐이었습니다. 시범 결과: 챕터로 2편, 공개 장면으로 3편, 설명란으로 2편의 구간을 정했습니다.

## 4. 지금 정해 두는 규칙 (나중에 돈을 벌 때를 대비)

PM 권고를 받아들여, 비용이 거의 들지 않는 지금 두 가지를 정해 둡니다.

1. **영상마다 `license` 표시**를 붙입니다.
   - `commercial-ok`: 상업 이용에 제한이 없는 퍼가기
   - `nc-only`: 비영리 조건(TED · 니코니코)
   - `yt-api`: YouTube API 로 받은 정보
2. **규칙**
   - 유료 페이지에는 `nc-only` 영상을 넣지 않습니다.
   - YouTube API 정보가 있는 페이지에는 광고를 넣지 않습니다.
   - 나중에 돈을 받는다면, 파는 것은 영상이 아니라 **「고르고 해설을 쓰는 일」**입니다.

## 5. 갤러리 1호를 재는 방법

Step 0 의 방문 기록 방식을 그대로 쓰고, 이벤트 3개만 더 셉니다. 리저브 링크로 처음 들어온 방문(`src=r`)은 빼고 셉니다.

| 지표 | 뜻 |
|---|---|
| ① 링크를 받은 날이 아닌 날에 갤러리를 다시 연 사람 수 | 스스로 다시 찾아오는가 |
| ② 한 번 방문에서 3편 이상 재생 | 둘러보는 즐거움이 있는가 |
| ③ 「공유」 버튼으로 남에게 전한 횟수 | 자랑하고 싶은 전시인가 |

마지막 인터뷰에 질문 하나를 더합니다. **「다음 갤러리 테마로 뭘 보고 싶나요?」** 시키지 않아도 구체적인 테마가 나오면 즐거움의 신호로 봅니다.

**한계.** 지인 5명은 예의상 좋게 반응할 수 있습니다. 모르는 사람의 반응은 공개 커뮤니티에 갤러리를 올려 봐야 알 수 있지만, 외부 게시라서 그때 다시 정합니다.
