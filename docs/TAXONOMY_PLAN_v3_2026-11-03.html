2. 자연과 우주관이 작다

우주·생명의 묶음 대부분(코스모스·기후·몸)은 학습관 강좌가 되었습니다. 그래서 자연과 우주관은 3개로 시작합니다(결정 ②). 「쉬면서 보는 자연」 묶음(심해·극지·밤하늘·새)을 자연 큐레이터에게 몇 개 더 맡기기를 권합니다.

3. 옛 링크를 지킨다 (PM 체크리스트)

  • 옛 주소 #/g?door=subject…, door=who, feat=…로 들어오면 새 관이나 찾기로 보낸다. 빈 화면이 되지 않게 한다.
  • 공유 미리보기 페이지 s/t-*.html(8개) · s/f-*.html(5개)는 지우지 않고, 가리키는 곳과 미리보기 문구만 새 자리로 다시 만든다.
  • 「트렌드」는 이름만 「지금」으로 바꾸고 주소 #/now는 그대로 둔다(북마크 보존).
  • 린트의 「자리 하나」 검사를 관 기준으로 바꾼다(미배치 0 · 중복 0).
  • 매주 재생 점검 Action 의 다시 빌드가 통과하는지 확인한다.

4. 결정할 것

  1. 남은 4개 묶음을 학습관에 위 표대로 들일지(또는 다른 관으로)
  2. 자연과 우주관을 3개로 시작하고 묶음을 더 만들지
  3. 관 안의 칸 이름(무대와 실황 · 보는 눈 · 만드는 손 · 처음과 끝 등)을 이대로 둘지
